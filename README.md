# Portal nexus search

Find a teleport destination in your player owned house portal nexus by typing its name.

## How to use

1. Enable **Portal nexus search** in RuneLite.
2. Open the teleport menu on your portal nexus.
3. Press **Command+F** on macOS or **Ctrl+F** on Windows and Linux.
4. Type a destination name in the chatbox to filter the list.
5. Click a matching destination to teleport or scry as usual.

You can type part of a name, and capitalization does not matter. Search includes available alternative destinations.

Press **Escape** or the search hotkey again to restore the full list and its shortcuts. Closing the nexus menu also closes search.

## Settings

Change **Search hotkey** in the plugin settings to use a different key combination. The hotkey works while the nexus teleport menu is open.

## Other plugins

**Better Teleport Menu** can stay enabled. Its destination shortcuts pause while you search and return when search closes.

If you use **Nexus Menu Map**, switch it to list mode before searching.
